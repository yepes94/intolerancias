🔑 Tus API keys

Se guardan solo en tu navegador (localStorage). Nada se envía a ningún servidor propio. Para producción usa el .env del servidor (npm start).

❓ Preguntas frecuentes

¿Dónde consigo cada clave?

Cada tarjeta tiene el botón “Conseguir key ↗” que te lleva a la consola oficial del proveedor. En general: crea una cuenta → sección API keys → Create key → cópiala y pégala aquí.

¿Es seguro guardarlas en el navegador?

Para uso personal está bien. Las claves quedan en localStorage de tu dispositivo y solo se usan para llamar directamente a la API del proveedor. No las compartas ni las subas a Git. Para compartir el proyecto, usa el fichero .env (ya ignorado por Git) junto al proxy server.js.

¿Por qué falla “Probar conexión”?

Lo más común: clave mal copiada (espacios de más), sin saldo/límites en el proveedor, o bloqueo CORS del navegador. Si el navegador bloquea la llamada directa, arranca el proxy con npm install && npm start y vuelve a probar.
